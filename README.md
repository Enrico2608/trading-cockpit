# trading-cockpit

Privates Trading-Cockpit. Alles ist verschlüsselt und öffnet sich nur mit Passwort.

- `index.html` – Anmeldeseite (entschlüsselt im Browser)
- `cockpit.json` – verschlüsseltes Cockpit
- `version.txt` – aktuelle Version

Schlüssel und Werkzeug für neue Versionen liegen privat, nicht in diesem Repository.
